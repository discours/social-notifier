# social-notifier — договор для агентов

Сервис уведомлений: GitHub Actions раз в 10 минут читает соцсети и пишет в Telegram. Устройство и настройка — [README.md](README.md) и [docs/setup.md](docs/setup.md), страницы сетей — [docs/sources/](docs/sources).

## Гейт

```bash
npm run typecheck && npm test
```

Зелёный — нулевой код возврата обеих команд. CI (`.github/workflows/ci.yml`) гоняет то же на Node 22 и 24.

## Правила

- Node 22.18+, TypeScript исполняется напрямую (type stripping). Только стираемый синтаксис: без `enum`, `namespace`, parameter properties; импорты с расширением `.ts`. Зависимостей во время работы нет — новая требует обоснования.
- **Логи публичные.** Секреты не попадают в лог, алерт и состояние: тексты ошибок проходят через редактор (`makeRedactor`). Не логировать адреса запросов (у Telegram токен в пути), заголовки, тела ответов API целиком. Тексты постов и названия страниц — публичный контент; обычный запуск их не логирует, dry-run и проба — можно.
- Доставка «хотя бы раз»: пост снимается с очереди после того, как Telegram принял его сообщение. Сбой источника или формата ответа должен доходить до алерта (`collectPosts` превращает целиком неразобранный ответ в `bad_response`, `runRadar` записывает сбоем и частично неразобранный), а не превращаться в «новых постов нет».
- Отметки `alertedAt` и `alertRedAt` успехом не сбрасываются, а стареют за сутки: иначе источник, сбоящий через раз, шлёт алерт, «снова отвечает» и письмо GitHub каждые полчаса. Тест «мигающий источник» это проверяет.
- Токены — только в заголовке или теле запроса, никогда в query string. Тест `токены VK и Meta не попадают в адрес запроса` это проверяет.
- Запросы к Graph API — с явным `fields`: без него ответ `me/accounts` содержит токены страниц.
- Workflow с секретами — только `schedule` и `workflow_dispatch`; `pull_request_target` не использовать. Экшены закрепляются по SHA с комментарием версии.
- Повреждённое состояние — ошибка запуска, а не тихий сброс: сброс прислал бы архив постов заново.
- Пост, вышедший до `watchingSince` источника, — архив, даже если радар видит его впервые (вырос `fetchLimit`, закрепили старый пост). Без `watchingSince` архива нет: подставленное «сейчас» проглотило бы каждый новый пост.
- Тексты для людей — сообщения, алерты, логи, вывод пробы, ошибки — живут только в каталоге `src/i18n/`: ключ в интерфейсе `Texts` (`index.ts`), текст в `en.ts` и `ru.ts`. Ошибка хранит фразу `(t) => t.…` и показывается на языке конфига (`language`, без поля — `en`). Литералов с кириллицей вне `ru.ts` нет — тест «вне src/i18n/ru.ts в литералах кода нет кириллицы». Текст каталога экранируется как любой другой: разметку ставит только код. Два исключения, где язык конфига недоступен: подписи, `echo` и `::error::` в `.github/workflows/*.yml` — по-английски; ошибка непрочитанного файла конфига и конфига, который не JSON-объект, — на языке по умолчанию.
- То, что видит «Дискурс» (`"language": "ru"`), держит эталон `test/fixtures/discours-ru.json` байт в байт — кроме двух ошибок конфига из исключения выше. Осознанная правка русского текста — `UPDATE_GOLDEN=1 node --test test/discours-ru.test.ts` и дифф эталона в PR; случайное расхождение — дефект.
- Комментарии — по-русски, код и идентификаторы — по-английски. Документация — английская в `*.md` и русская рядом в `*.ru.md`, первой строкой под заголовком переключатель языка; правится парой.
- Тесты — `node:test`, внешние API подменяются `FakeWorld` из `test/helpers.ts` или `fakeFetch` из `test/sources.test.ts`. Новая логика отбора или отправки получает тест, который краснеет при её поломке.
- Сеть — адаптер в `src/sources/` и строка в реестре `src/sources/index.ts`; ядро о сетях не знает. Порядок и правила — [docs/adding-a-source.md](docs/adding-a-source.md). Секрет сети прописывается в трёх местах (`SOURCE_SECRETS`, `secrets` адаптера, `env` шагов `radar.yml` и `probe.yml`); тест «каждый секрет передан» их сверяет, пример источника на странице сети проверяется как конфиг.
- Платная сеть просит только посты новее виденных (`ctx.known`): каждый лишний пост в ответе стоит денег.
- **Ответ сети — чужой ввод, и разбор синхронный:** квадратичный разбор одного ответа останавливает опрос всех сетей и алерты. Поэтому ответ не длиннее `MAX_RESPONSE_BYTES` (`readText`), а текст разбирается за линейное время: поиск через `indexOf` с движением вперёд, без регулярок с ленивыми или вложенными квантификаторами по чужому тексту. Тест «враждебная лента разбирается за линейное время» краснеет на квадратичном разборе за секунды.
- Обращение в текстах для людей — на «вы»; алерт начинается с сети и давности сбоя, код ошибки — последним, за ним только ссылка на лог запуска.
