# Telegram-каналы

[English](telegram.md) · **Русский**

Открытый канал читается со страницы предпросмотра `t.me/s/<канал>` — той, что Telegram показывает в браузере без входа. Ключ не нужен, добавлять бота в канал не нужно.

**Что нужно:** только открытое имя канала. **Цена:** бесплатно.

## Источник в конфиге

```json
[
  { "id": "telegram", "type": "telegram", "label": "TG", "channel": "discoursio" },
  { "id": "iskra", "type": "telegram", "label": "Iskra", "channel": "mediaiskra" }
]
```

`channel` — открытое имя без `@`, как в `t.me/discoursio`: латиница, цифры и `_`, от 4 до 32 символов. Каждый канал — отдельный источник со своими `id` и `label`.

## Что приходит

- Посты канала, включая пересланные. Альбом — одно уведомление.
- Служебные сообщения — «канал создан», «закреплено», новое фото канала — не приходят.
- Время поста — время публикации; правленый пост второй раз не приходит.
- В предпросмотре видно около 20 последних сообщений (альбом считается за несколько). Если канал между двумя опросами опубликует больше, ранние пропадут.

## Ограничения и риски

- **Предпросмотр — разметка сайта, а не API.** Telegram может поменять её без предупреждения. Тогда посты перестанут распознаваться, и со второго запуска придёт алерт с видом `bad_response` — радар никогда не решит молча, что новых постов нет. Чинится в [`src/sources/telegram.ts`](../../src/sources/telegram.ts).
- **Правила Telegram не описывают автоматическое чтение предпросмотра.** Радар открывает страницу так же, как браузер: один запрос на канал за опрос, без входа.
- **Только открытые каналы.** У закрытого канала, группы, пользователя или бота предпросмотра нет: `t.me` уводит на карточку профиля, и алерт просит проверить конфиг.
- Канал без единого сообщения — даже без служебного «канал создан» — считается сменившейся разметкой.

## Почему не Bot API

Bot API не умеет читать историю канала. Бот-администратор канала получает новые посты как обновления `channel_post` через `getUpdates`, но Telegram хранит их только 24 часа, бот должен быть администратором каждого канала, включая чужие, а радар спорил бы за те же обновления с `find_chats` пробы. Предпросмотр работает для любого открытого канала и ничего не требует от его владельцев.
