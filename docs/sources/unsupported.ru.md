# Сети, которых пока нет

[English](unsupported.md) · **Русский**

Проверено 8 ноября 2026 года по документации сетей. Здесь написано, что мешает каждой сети и что изменило бы решение.

## TikTok

Список видео аккаунта отдаёт только Display API (`/v2/video/list/`), и только с OAuth-входом владельца аккаунта. Две преграды:

- **Токен меняется сам.** Токен доступа живёт 2 часа, refresh-токен — 180 дней, и каждое обновление выдаёт новый refresh-токен ([документация](https://developers.tiktok.com/doc/oauth-user-access-token-management)). Workflow должен был бы перезаписывать секрет каждые два часа. Для этого нужен личный токен GitHub с правом записи секретов, а одна неудачная запись рвёт цепочку, и тогда требуется новый вход человека.
- **Аудит приложения.** Нужны сайт, политика конфиденциальности, демо-видео, и приложение не должно быть «для личного использования» ([правила ревью](https://developers.tiktok.com/doc/app-review-guidelines)).

Изменило бы решение хранилище секретов, в которое workflow может писать (например, Cloudflare KV), или появление у TikTok токенов, которые не меняются при обновлении.

## Threads

[Threads API](https://developers.facebook.com/docs/threads) читает посты пользовательским токеном Threads, а не токеном системного пользователя Meta. Долгоживущий токен действует 60 дней, и продление выдаёт новый токен. Значит, раз в 50–60 дней человек должен вручную выпускать токен и обновлять секрет; пропустил — алерт `auth`.

Адаптер несложный (`GET /{user-id}/threads`, повторы помечены `REPOST_FACADE`). Его стоит делать, если ручное продление раз в два месяца приемлемо.

## LinkedIn, Дзен, Одноклассники

- **LinkedIn:** посты страницы компании отдаёт только Community Management API, доступ к нему выдаётся по заявке.
- **Дзен:** публичного API и экспорта ленты нет, есть только импорт сайта в Дзен.
- **Одноклассники:** официальной документации метода для постов группы найти не удалось.
