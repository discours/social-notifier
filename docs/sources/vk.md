# VK

Посты сообщества читаются методом [`wall.get`](https://dev.vk.com/ru/method/wall.get) сервисным ключом приложения. Ключ не привязан к личному аккаунту: смена пароля или выход из сессии его не ломают.

**Что нужно:** приложение VK ID и его сервисный ключ. **Цена:** бесплатно.

## Ключ

1. В кабинете разработчика [VK ID](https://id.vk.com/) создайте приложение.
2. В настройках приложения скопируйте **сервисный ключ доступа**. Он читает открытые стены сообществ.
3. Сохраните его в секрет:

   ```bash
   gh secret set VK_TOKEN --repo OWNER/REPO
   ```

## Источник в конфиге

```json
{ "id": "vk", "type": "vk", "label": "VK", "ownerId": -89236419 }
```

`ownerId` — ID стены. У сообщества это минус числовой ID: для `vk.com/club89236419` — `-89236419`. Короткий адрес переводится в ID методом [`groups.getById`](https://dev.vk.com/ru/method/groups.getById).

## Что приходит

- Посты от имени сообщества, включая репосты на его стене; у репоста без своего текста в сообщении — текст исходной записи.
- Не приходят предложенные записи и записи посетителей (`filter=owner`).
- Закреплённый старый пост не придёт: он вышел до начала наблюдения.
